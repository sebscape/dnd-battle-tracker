# Scrap Sheet

A 5E-compatible battle tracker for game masters: plan encounters, roll initiative, and track hit points, conditions and turns.

Live at https://scrap-sheet.c2ma.com. Companion app: [Critter Codex](https://critter-codex.c2ma.com), a monster reference.
